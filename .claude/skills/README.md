# Project Skills

These design/engineering skills were added to the repo so Claude Code sessions
can load and apply them. They are **third-party community skills** fetched from
their canonical public GitHub sources. Only the instruction files (`SKILL.md`)
were installed — bundled helper scripts / npm packages were intentionally **not**
included or executed.

| Skill | Source repo |
|-------|-------------|
| `ui-ux-pro-max`         | https://github.com/nextlevelbuilder/ui-ux-pro-max-skill |
| `design-taste-frontend` | https://github.com/bnd-1/taste-skill |
| `emil-design-eng`       | https://github.com/emilkowalski/skills |
| `impeccable`            | https://github.com/pbakaus/impeccable |
| `karpathy-guidelines`   | https://github.com/multica-ai/andrej-karpathy-skills |

Licenses belong to the respective authors (see each `SKILL.md` frontmatter where
provided). Re-download from source to get the full skill (scripts/data) if needed.
