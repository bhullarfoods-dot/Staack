# UI icons (wallet + buy crypto + coin)

Small brand/UI icons used in the chrome.

## Files (filename = key below)
| Key          | Where it shows                                            |
|--------------|-----------------------------------------------------------|
| `buy-crypto` | Icon on the "Buy Crypto" button (bottom-left of sidebar)  |
| `currency`   | Currency icon in the wallet/balance (top bar, the ₿)      |
| `node`       | The round "NODE" coin mark next to the price (top bar)    |

→ e.g. `buy-crypto.svg`, `currency.svg`, `node.png`

## Specs
- **Square 1:1.** `.svg` ideal; transparent `.png`/`.webp` fine.
- `currency` / `node` display ~18 px; `buy-crypto` ~18–20 px.

Files map into `assets/img/manifest.json` under `"ui"`.
