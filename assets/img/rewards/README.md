# "Next rewards" icons

The 3 icons in the loyalty "Next rewards" list. Each swaps from its gradient glyph
to your image once it loads.

## Files (filename = key)
| Key             | Row             |
|-----------------|-----------------|
| `weekly-bonus`  | Weekly bonus    |
| `rakeback-boost`| Rakeback boost  |
| `free-case`     | Free case       |

→ e.g. `weekly-bonus.png`, `rakeback-boost.webp`

## Specs
- **Square 1:1.** Suggested **96 × 96**. Transparent PNG/WebP ideal (shown ~32 px).

Files map into `assets/img/manifest.json` under `"rewards"`.
