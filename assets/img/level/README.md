# "Current level" — badge + character

Two assets for the loyalty "Current level" tile.

## Files (filename = key)
| Key         | What                                                         |
|-------------|--------------------------------------------------------------|
| `badge`     | The square rank badge (replaces the "04" tile, ~62 px)       |
| `character` | A character/mascot shown on the right side of the tile       |

→ e.g. `badge.png`, `character.png`

## Specs
- **badge:** square 1:1, ~128 × 128, transparent PNG/WebP.
- **character:** tall/portrait, transparent PNG/WebP, ~500 px tall. Anchored bottom-right.

Files map into `assets/img/manifest.json` under `"level"`.
