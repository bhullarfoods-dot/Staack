# Self-exclusion section character

A single character/mascot shown on the right side of the "Self exclusion" section
(above the footer). Hidden on smaller screens (≤980px) so it never overlaps the text.

## File (filename = key)
| Key         | Where                                   |
|-------------|-----------------------------------------|
| `character` | Right side of the self-exclusion banner |

→ e.g. `character.png`

## Specs
- **Transparent PNG/WebP**, portrait/full-body. Suggested **~500–700 px tall**.
- Anchored bottom-right; faces left (toward the text) if possible.

Files map into `assets/img/manifest.json` under `"excl"`.
