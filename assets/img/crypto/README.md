# Crypto / payment coin icons

Coin logos for the "Accepted crypto" row in the footer (bottom of the homepage).
Each chip swaps from its text label to your icon once it loads.

## Files (filename = ticker, lowercase)
`btc` · `eth` · `usdt` · `sol` · `ltc` · `xrp` · `doge` · `ton`

→ e.g. `btc.svg`, `eth.svg`

Add more tickers if you want — just tell me the names and I'll list them too.

## Specs
- **Square 1:1.** Suggested **64 × 64**. `.svg` ideal (crisp); transparent `.png`/`.webp` fine.
- Official coin colors are great here; they sit on a dark chip.

Files map into `assets/img/manifest.json` under `"crypto"`.
