# NodeRoll Originals — card images

Dedicated card art for the **NodeRoll Originals** rail, so it doesn't reuse the same
images as the Top/New/Slots grids. Each card swaps from its SVG to your image on load.

## Files (filename = key)
`mines` · `crash` · `dice` · `plinko` · `hilo` · `wheel` · `tower` · `keno` · `limbo` · `coinflip`
→ e.g. `mines.webp`, `crash.webp`

## Specs
- **Aspect ratio:** 3 : 4 portrait. Suggested **480 × 640**.
- `.webp` / `.png` / `.jpg` / `.avif` all fine.

Files map into `assets/img/manifest.json` under `"originals"`.
