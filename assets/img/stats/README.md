# Loyalty stat icons

A small icon for each of the 3 stat tiles (shown top-right of each tile).

## Files (filename = key)
| Key       | Tile            |
|-----------|-----------------|
| `wagered` | Total wagered   |
| `wins`    | Total wins      |
| `drops`   | Rains & drops   |

→ e.g. `wagered.png`, `wins.webp`

## Specs
- **Square 1:1.** Suggested **96 × 96**. Transparent PNG/WebP (shown ~36 px).

Files map into `assets/img/manifest.json` under `"stats"`.
