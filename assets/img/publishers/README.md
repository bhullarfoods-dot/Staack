# Game publisher / provider logos

Logos for the "Publishers" row under the hero. Each card swaps from its text wordmark
to your logo once it loads.

## Files (filename = key)
| Key         | Provider        |
|-------------|-----------------|
| `stake`     | Stake           |
| `pragmatic` | Pragmatic Play  |
| `hacksaw`   | Hacksaw Gaming  |
| `evolution` | Evolution       |
| `nolimit`   | Nolimit City    |
| `twist`     | Twist           |
| `massive`   | Massive Studios |
| `paperclip` | Paperclip Gaming|

→ e.g. `stake.svg`, `pragmatic.png`

Want different/more providers? Upload them and tell me the names — I'll add cards.

## Specs
- **Wide wordmark logos**, transparent background. Suggested height **~40 px** (e.g. 240 × 80).
- **Light/white logos work best** on the dark cards. `.svg` ideal; `.png`/`.webp` fine.

Files map into `assets/img/manifest.json` under `"publishers"`.
